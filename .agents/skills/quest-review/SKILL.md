---
name: quest-review
description: Review a PR's branch locally with a model no weaker than its latest writer, then mark it ready for review.
---

Run `quest skill review` and follow its output.
If `quest` is not on `PATH`, run `nix develop --command quest skill review` instead, and prefix later `quest` commands with `nix develop --command` except where the skill asks for a `quest` the PR cannot modify; if that fails too, follow https://github.com/kixel-ai/quest/blob/main/SETUP.md first.
