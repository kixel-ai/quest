---
name: quest-import
description: Import GitHub issues as quests.
---

Run `quest skill import` and follow its output.
If `quest` is not on `PATH`, run `nix develop --command quest skill import` instead, and prefix later `quest` commands with `nix develop --command` except where the skill asks for a `quest` the PR cannot modify; if that fails too, follow https://github.com/kixel-ai/quest/blob/main/SETUP.md first.
